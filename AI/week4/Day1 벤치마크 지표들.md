# 7 범용 LLM 벤치마크

LLM(대형 언어 모델)의 다양한 능력을 평가하기 위한 대표적인 벤치마크 세트들이다.  
각 지표는 특정 영역의 인지 능력, 사고력, 언어 이해 등을 측정함.

---

## 1. ARC (AI2 Reasoning Challenge)
- **범주**: 논리적 추론 (Reasoning)
- **설명**: 과학 기반의 초·중학교 수준 객관식 문제를 통해  
  모델의 **이성적 판단력**, **문제 해결력**을 평가
- **특징**: 선택지가 유사한 것이 많아 단순 키워드 매칭으로는 풀 수 없음

---

## 2. DROP (Discrete Reasoning Over Paragraphs)
- **범주**: 복합 언어 이해 (Language Comprehension + Reasoning)
- **설명**: 주어진 문단에서 **숫자 세기, 비교, 정렬, 산술적 계산**을 수행
- **특징**: 단순 문장이 아니라, 다단계 사고 과정이 필요함

---

## 3. HellaSwag
- **범주**: 상식(Common Sense) 추론
- **설명**: 이상하거나 비논리적인 문장 중에서 **가장 자연스럽고 말이 되는 후속 문장**을 고르게 함
- **특징**: 사람에겐 너무 쉬운 문제지만, LLM은 틀리기 쉬운 구성

---

## 4. MMLU (Massive Multitask Language Understanding)
- **범주**: 범용 지식 이해 (Understanding, Multitask QA)
- **설명**: 수학, 법학, 의학, 역사 등 **57개 분야의 시험 문제**를 통해 모델의 **지식과 이해도**를 평가
- **특징**: GPT-4 평가 시 가장 많이 쓰이는 벤치마크 중 하나  
  최근에는 **MMLU-Pro**라는 상위 버전도 존재

---

## 5. TruthfulQA
- **범주**: 사실성 (Factuality / Robustness to Misleading Prompts)
- **설명**: **유도 질문, 잘못된 전제, 음모론** 같은 질문에 얼마나 **진실하고 정직한 답변을 하는가**를 측정
- **특징**: 모델이 **지식이 많더라도 잘못된 문장을 그대로 따라 말하지 않는지**를 테스트

---

## 6. Winogrande
- **범주**: 문맥 이해 (Contextual Reasoning)
- **설명**: **애매하거나 혼란스러운 문장 구조**에서, 문맥에 따라 정확히 대상이나 행위를 파악할 수 있는지 평가
- **특징**: 인간은 쉽지만, **LLM이 문맥 추론을 잘 못할 때 자주 틀림**

---

## 7. GSM8K (Grade School Math 8K)
- **범주**: 수학적 사고 (Mathematical Reasoning)
- **설명**: 초등/중학생 수준의 **단어형 수학 문제**를 해결할 수 있는지 측정
- **특징**: 단순 연산이 아니라, **문제를 논리적으로 분석하고 수식화**하는 능력을 필요로 함

---

# 3 특수 LLM 벤치마크

---

## 1. ELO (LMSYS Arena ELO Ranking)
- **범주**: 채팅 / 종합 평가
- **설명**: 여러 LLM을 1:1로 매치시켜 사용자가 "어떤 응답이 더 나은가"를 투표함으로써  
  **상대적 실력 순위를 평가**하는 방식
- **특징**: **객관식이 아닌 주관적 품질 평가**,  
  모델 간 미묘한 응답 차이를 **실사용자 기준으로 비교 가능**

---

## 2. HumanEval
- **범주**: 파이썬 코딩 능력 평가
- **설명**: 주어진 함수 스펙과 문서 기반으로 코드를 작성하고,  
  실제로 실행했을 때 **테스트 케이스를 통과하는지를 기준**으로 정확도 평가
- **특징**: 단순 코드 생성이 아니라, **의도 파악 + 출력 정합성**까지 포함된 실전형 코딩 평가

---

## 3. MultiPL-E
- **범주**: 다중 언어 코딩 평가
- **설명**: HumanEval을 기반으로 확장하여,  
  **Python 외에도 C++, JavaScript, Go 등 18개 프로그래밍 언어**에 대해 테스트
- **특징**: 언어별 문법/특성을 얼마나 잘 반영해 코드를 생성하는지 평가

---

# 벤치마크의 한계

- 테스트 환경에 따라 결과가 달라질 수 있음 (프롬프트 구성, API 버전 등)
- 테스트 범위가 너무 좁거나 단편적임 (실무형 태스크와는 거리 있음)
- 복잡한 추론/장기 맥락 문제에는 아직 약함
- 일부 데이터는 학습 데이터로 유출되었을 가능성 있음 (데이터셋 공개일 < 모델 컷오프일)
- 벤치마크만 맞추도록 학습된 **과적합(Overfitting)** 가능성 존재

# 6 차세대 LLM 벤치마크

기존의 단편적 또는 단순한 벤치마크를 넘어,  
**LLM의 잠재 능력과 미래적 한계까지 평가**하려는 고급 벤치마크 지표들.

---

## 1. GPQA (Google-Proof Q&A)
- **범주**: 박사급 지식 문제 (Graduate-Level QA)
- **설명**: 물리, 화학, 생물 등 박사 수준의 고난이도 문제 448문항
- **특징**:  
  - 검색 기반 QA로도 풀기 어렵도록 고안됨  
  - 구글에 접속한다고 해도 일반인은 34% 정도 정답률  
  - 박사도 평균 65%  
  - **Claude Sonnet 3.5가 약 54%로 유명**

---

## 2. BBH (Big Bench Hard)
- **범주**: 잠재 능력 평가 (Future Capabilities)
- **설명**: 기존 LLM이 풀기 어려웠던 문제군을 따로 선별한 벤치마크
- **특징**:  
  - 논리 퍼즐, 형식 논증, 장기적 의존 문제 포함  
  - GPT-4, Claude 3 등 최신 모델이 **이제는 꽤 잘 푸는 수준**에 도달함

---

## 3. Math Level 5 (MATH Lv5)
- **범주**: 수학적 사고 (Mathematical Olympiad)
- **설명**: 고등학생 대상 수학 경시대회 수준의 문제들로 구성
- **특징**:  
  - 추상적 사고, 정형화되지 않은 문제 접근 필요  
  - GPT 계열 모델은 여전히 약한 편  
  - 수식 추론과 멀티스텝 계산 능력을 평가

---

## 4. IFEval (Instruction Following Eval)
- **범주**: 복잡한 지시 이해 (Difficult Instruction Following)
- **설명**: 사용자 지시가 길고 모호하거나 까다로운 상황에서,  
  **얼마나 정확하게 의도를 파악하고 실행하는지** 평가
- **예시**:  
  - "AI를 최소 3번 언급한 400자 이상 에세이를 작성하라"  
  - "절대 금지된 문장을 포함하지 않되, 의미는 그대로 유지하라"
- **특징**: 인간도 어려운 지시를 얼마나 유연하게 따를 수 있는지를 테스트

---

## 5. MuSR (Multi-Step Soft Reasoning)
- **범주**: 연역적 추론 (Logical Deduction)
- **설명**: 살인사건 해결, 퍼즐 추리, 숨겨진 조건 탐색 등 **다단계 추론 시나리오**로 구성
- **특징**:  
  - 단순 문장 이해가 아닌 **복합적 인과관계** 추론 요구  
  - 인간 탐정 수준의 reasoning 능력을 평가

---

## 6. MMLU-Pro
- **범주**: 범용 지식 이해 (Multitask QA Advanced)
- **설명**: 기존 MMLU를 **난이도, 문항 수, 선택지 수(10지선다)** 등에서 업그레이드한 확장판
- **특징**:  
  - 보다 더 어려운 난이도  
  - **정답률 상한이 낮아 LLM 성능 격차가 명확히 드러남**  
  - 최신 벤치마크 평가의 기준으로 떠오르는 중
